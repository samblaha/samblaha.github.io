The numbers

Display
0 in e-paper, LilyGo T5
Portrait buffer
0 × 0 px on landscape-native hardware
Grayscale
0 levels and an image blitter that respects them
Memory
0 MB flash · 0 MB PSRAM framebuffers live in the latter
Formats
EPUB · TXT · CBZ straight off the SD card

The numbers are the easy part. The hard part was pagination that wraps words on an embedded chip, a battery gauge that respects the LiPo discharge curve, and a dual-sleep strategy so the thing wakes instantly and still lasts. Read the full build log for the honest version.
